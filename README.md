# Falcon Download Manager — Public Update Channel

Public release metadata and update-distribution channel for **Falcon Download Manager**.

> This repository is intentionally limited to public update metadata and release assets.  
> Application source code, private operational data, and real license records must not be stored here.

## Purpose

Falcon Download Manager uses this repository as a lightweight public channel for:

- publishing the latest application version;
- providing the current release download URL;
- publishing release notes and compatibility metadata;
- exposing non-sensitive client update settings for testing and distribution.

The current public metadata is stored in `server.json`.

## Repository contents

- `server.json` — public update metadata and demo-only license data.
- `FalconDM_StepByStep.rar` — packaged project documentation / reference material.
- GitHub Releases — distributable Falcon DM builds.

## Security policy

This is a **public repository**. Never commit:

- real license keys;
- customer or personal email addresses;
- API tokens, passwords, or credentials;
- private customer data;
- production secrets.

Only synthetic/demo records are permitted in the public configuration.

If a real credential or license record is accidentally published, remove it from the current configuration and rotate or invalidate it immediately.

## Current release

The public update configuration currently targets Falcon DM **v1.0.3**.
